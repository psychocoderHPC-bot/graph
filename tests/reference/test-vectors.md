# RNG test vectors for the particle-feedback example

Generated by the canonical `oracle.cpp` (contract in `docs-rng-spec.md`).
Each case runs with `maxVisits=1000000`. Output format: header,
`histogram: weight count` rows (sorted ascending, destroyed only),
`total`, `nonTerminating`, `maxVisit`, `fnv1a`. The FNV-1a checksum
covers only destroyed particles, in ID order. These vectors are the
GPU/CPU acceptance fixtures; rerunning the oracle must reproduce them
byte-for-byte.

With the corrected double-splitmix64 generator, **nonTerminating is 0 for
every case** and `maxVisit` is the true maximum visit count (well below the
guard). The per-round survival probability is exactly 1/2, so
P(alive after k rounds) = 2^-k and the example terminates almost surely.

variables is around 18-25, consistent with the observed 16 and 20.
